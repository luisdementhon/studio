# **App Name**: Dotly

## Core Features:

- User Onboarding: Guided onboarding process to determine user type (individual or association) and gather necessary information like personal/organizational details, preferences for causes/associations, and donation preferences (multiplier, ceiling).
- Association Onboarding: Collect required data: association name, contact information, RNA number, information about the association, fundraising goals and current missions, including automated verification for tax receipt eligibility.
- User Donation Customization: Enable users to set donation preferences: donation multiplier (based on income), maximum weekly/monthly donation amount, and preferred causes/associations. Allow modifications after onboarding.
- Rounded-Up Transaction Processing: Process credit card transactions, round them up to the nearest euro, and earmark the difference for donation.
- Association Dashboard: Provide associations with a dashboard to monitor donations, track progress, and view insightful data visualizations.
- User Donation Dashboard: Provide users with a personalized dashboard showing donation history, total amount donated, and impact metrics, plus single-donation button.
- Profile and Settings: Profile and Settings Page: standard options plus Multiplier / max ceiling on donations.

## Style Guidelines:

- Primary color: Deep purple (#5856D6) for a modern and trustworthy feel, reminiscent of established financial tech brands.
- Background color: Very light grey (#F4F5F7) provides a clean and unobtrusive backdrop that allows the deep purple accents to stand out. Provides excellent legibility for all on-screen elements.
- Accent color: Vibrant pink (#FF2D55) complements the purple and adds an element of excitement, particularly for highlighting donation milestones or calls to action.
- Body and headline font: 'Inter', a versatile sans-serif, known for its readability and modern appearance, suitable for both headlines and body text.
- Use clear, simple icons to represent different causes and settings. Icons should follow a consistent style.
- Design a clean and intuitive user interface with clear navigation. Prioritize the donation dashboard with visually appealing data visualizations.
- Incorporate subtle animations and transitions to enhance user engagement, like smooth loading animations, value changes in real-time etc. to create an intuitive feel.
